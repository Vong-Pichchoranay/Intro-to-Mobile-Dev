# Assignment01: Simple Portfoilio

Welcome to Assignment01 in our Introduction to Mobile Development Course!
In this assignment, students will develop a personal portfolio mobile app using Flutter, following
a provided Figma design sample. This app will showcase their profile, skills, and work, serving
as a professional portfolio piece.
